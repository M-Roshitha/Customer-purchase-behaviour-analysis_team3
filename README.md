Problem Statement
Businesses often struggle to understand customer purchasing patterns due to large volumes of transactional data. This lack of understanding leads to inefficient marketing strategies and potential revenue loss. The project aims to analyze customer purchase behaviour using data mining techniques to extract meaningful insights and support better business decision-making. 

Objectives
•	Analyze customer purchase behaviour to identify spending patterns 
•	Perform data cleaning and preprocessing for reliable analysis 
•	Explore trends using visualization techniques 
•	Segment customers based on purchasing behaviour 
•	Build a model to predict product categories 
•	Perform OLAP analysis for business insights 

Dataset
•	Source: Shopping Trends Dataset 
•	Number of Observations: ~3900 records 
•	Number of Variables: 19 attributes 
•	
Important Attributes:
•	Customer ID – Unique identifier 
•	Age – Customer age 
•	Gender – Male/Female 
•	Category – Product category 
•	Purchase Amount – Amount spent 
•	Season – Purchase season 
•	Previous Purchases – Past purchase count 
•	Payment Method – Mode of payment 
This dataset includes both categorical and numerical data, making it suitable for clustering, classification, and correlation analysis. 

Methodology
Data Preprocessing
•	Removed missing values and duplicates 
•	Converted categorical variables into factors 
•	Ensured data consistency and accuracy 
Exploratory Analysis (EDA)
•	Analyzed age distribution, gender distribution 
•	Studied purchase amount patterns 
•	Examined category-wise and seasonal sales 
Models Used
•	Clustering: K-Means (customer segmentation) 
•	Classification: Decision Tree (predict product category) 
•	Correlation Analysis: Heatmap to identify relationships 
•	OLAP Analysis: Aggregation for business insights 
Evaluation Methods
•	Cluster interpretation (high, medium, low value customers) 
•	Model understanding through decision tree structure 
•	Correlation strength analysis 
•	Business insight validation 

Results
•	Customers grouped into high, medium, and low spending segments 
•	Decision tree identified purchase amount and previous purchases as key factors 
•	Certain product categories contribute the highest revenue 
•	Seasonal trends significantly influence sales 
•	Previous purchases positively correlate with spending

How to Run the Project
Steps:
1.	Load dataset into R environment 
2.	Perform preprocessing (handle missing values, duplicates) 
3.	Conduct EDA using plots 
4.	Apply K-Means clustering 
5.	Build Decision Tree model 
6.	Perform OLAP analysis 
7.	Run interactive query system 

Conclusion
This project demonstrates how data mining techniques can effectively analyze customer purchase behaviour. It highlights the importance of preprocessing, visualization, clustering, classification, and OLAP analysis in extracting meaningful insights. The results help businesses improve marketing strategies, optimize product offerings, and enhance customer satisfaction through data-driven decisions.
