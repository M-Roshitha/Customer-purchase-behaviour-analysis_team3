The dataset used in this project is the Shopping Trends Dataset, which is a structured dataset
containing customer purchase information. It consists of approximately 3900 records and 19
attributes, representing customer demographics, transaction details, and purchasing behaviour. The dataset includes both categorical and numerical variables, making it suitable for various data
mining techniques such as clustering, classification, and correlation analysis. This dataset is particularly useful for analyzing customer behaviour as it combines demographic
information with transactional data. It enables the identification of spending patterns, customer
preferences, and seasonal trends.
Overall, the dataset provides a strong foundation for applying data mining techniques to extract
meaningful insights and support data-driven decision-making in a retail environment.
